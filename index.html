日语 YouTube 学习器 中文字幕界面 · 日文字幕增强

YouTube + AI 转写 + 自动校正 + 注音 + 单词/语法学习器

把日语视频变成可精读、可编辑、可复习的学习材料。

粘贴 YouTube 链接即可在页面内观看视频；优先导入你信任的日语字幕文本，应用会解析时间轴、同步高亮，并为常见汉字自动添加假名注音。

推荐流程

  1. 粘贴视频链接并加载播放器
  2. 导入人工校对字幕或 SRT/VTT 文本
  3. 播放时跟读同步字幕和 furigana
  4. 记录单词、语法点，后续可接入 AI 转写

第一步

输入 YouTube 视频链接

支持 youtube.com/watch、youtu.be、embed、shorts 链接。

AI 转写

AssemblyAI 日语转写

需要 API Key

在本地服务器设置 ASSEMBLYAI_API_KEY 后，可输入可公网访问的音频/视频文件直链生成日语字幕。注意：普通 YouTube 页面链接不是音频直链，建议先使用人工字幕，或后续接入 YouTube 音频提取服务。

转写完成后会自动填入字幕编辑区，并立即添加注音。
